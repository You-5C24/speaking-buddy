# speaking-buddy

飞书里的英语口语陪练。语音进，语音出，每次练习结束给一份逐句复盘。

**当前阶段：需求与设计，不写代码。**

## 定位

- **是验证场，不是终局产品**。先在飞书里跑通「开口 → 被理解 → 拿到反馈」这条闭环，验证教学法有没有用。渠道以后可以换（小程序 / 网页 / App），音频管线、评测、复盘逻辑是一层可复用的服务，飞书只是其中一个 adapter。
- **v1 服务一个人**：作者自己。
- **v1 只做单聊**，群聊/双人留到 v2（需要额外权限，且语音消息带不了 @，见 [02-飞书流转](02-飞书流转.md)）。

## 核心主张

> 这不是一个「会说英语的聊天对象」，是一个**有目标、有推进、有复盘**的练习系统。

三条设计红线：

1. **对话中不纠错**，只用重铸（recast）——用正确说法自然重复一遍，不点破。
2. **不给发音分数**，只给具体词、具体音。
3. **不做通用句型库**，只给「你刚才想说的那句」的更自然版本。

## 借鉴

结构上参照同目录 `agent-os`：WS 长连接收事件 → 事件分发 → 话题/会话映射 → 卡片与文档输出 → JSON 落盘。

可直接复用的部分：WS 接入、事件去重、`config/bots.json` 的多 bot 注册、卡片构造、文档写入。

需要新写的只有一层：**音频管线**（opus 下载 → 转码 → ASR → LLM → TTS → 转 opus → 带 duration 上传发送）。这层约两三百行，是整个项目里最不性感但最必须的部分。
